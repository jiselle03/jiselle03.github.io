## Design Context

### Users
Hiring managers, engineering leads, recruiters, and peers evaluating Jiselle Liu as a product-minded fullstack engineer with strong UI/UX judgment. They need to understand technical range, product judgment, interface craft, and proof of recent product work quickly.

### Brand Personality
Direct, capable, product-minded. The portfolio should feel memorable and intentionally designed without reading as gimmicky, over-animated, or generated from a generic template.

### Aesthetic Direction
Use three intentional systems documented in `DESIGN.md`. The portfolio is **Product Casebook**: a warm-paper, blue-black, yellow-signal editorial system of indexed case files, one active case, fold-out system maps, and marginal evidence notes. It must not become a faux desktop. Set is **Studio Roster Desk**: a screenshot-derived scheduled-class, live-roster, partner class-register, and platform-admin member-directory interface. This direction uses the user-provided travel-document reference images only; it is not claimed as an externally inspected system and must not copy aviation content or language. Small Walks is **Hypercard Stack Shoebox**: a screenshot-derived, near-monochrome stack interface with an indexed contents rail, one dominant current card, compact utility cards, and double-line frames. This direction uses the user-provided reference image only; it is not claimed as an externally inspected system. Taller Gráfica Linocut is held for a future writing/editorial page. Recent work remains NDA-safe and capability-led; no remote font, API, analytics, or client-data dependency is introduced.

### Design Principles
1. Lead with proof of work: project outcomes, technical decisions, and role clarity should be visible in the first meaningful viewport.
2. Keep each surface visually autonomous while sharing accessibility, 44px controls, sans-serif typography, and an 8px-based rhythm.
3. Make the craft visible: typography, layout, responsiveness, focus states, and micro-interactions should demonstrate frontend judgment.
4. Avoid portfolio cliches: no generic card grid, purple gradients, decorative metrics, or vague "passionate developer" copy.
5. Preserve accessibility as part of the brand: semantic HTML, keyboard support, contrast, reduced motion, and resilient mobile layouts are non-negotiable.

### Demo Direction
- Set is a fictional studio membership platform. It should feel like a studio front desk organized around a live class roster, not a generic SaaS dashboard. Its memorable proof point is a visible cause-and-effect change across member and partner views.
- Small Walks is a fictional local street-collecting game. It should feel like a useful physical stack of outing cards: observant and tactile, without turning into a social-network mockup or copying the reference’s content.
- First-time demo visitors need a concise scenario brief, then an equal choice to take the guided flow or explore freely. Use a centered dialog on desktop and a bottom sheet on phone widths.
