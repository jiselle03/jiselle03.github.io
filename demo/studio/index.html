          Product plan

          How Set could scale.

          The demo keeps the member, partner, and operations views in sync. A production service would enforce the same rules with accounts, permissions, and a transaction-backed schedule.

          Accounts and permissions

          People use individual accounts. Partner roles belong to each studio; Set operations roles stay separate. Every change checks role and organization scope and records who changed what.

          Classes and bookings

          Recurring class templates create dated sessions. Each booking checks eligibility and capacity, while an append-only credit ledger records charges, refunds, and adjustments.

          Operations and reliability

          Member schedules, partner rosters, and support records read from the same session and booking history. Production checks would cover permissions, duplicate requests, and concurrent bookings.
